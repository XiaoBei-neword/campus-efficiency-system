## 新主题实现要点

- 设计令牌全部重写：`--bg:#E7ECF3`、`--ink:#33465C`、`--hi:#FFFFFF`、`--sh:rgba(150,166,186,.62)`；粉彩语义色 blue/pink/mint/amber/danger + 深色 pastel-ink 保证正文可达 ~4.5:1 对比。
- 凸起 = `--shadow-out`（严格 `-5px -5px 15px` / `5px 5px 15px`），小构件等比缩到 -3/8、-2/6；凹陷 = `--shadow-in`。
- 全部组件覆盖：顶栏（浅色+凹陷时钟）、统计条（凸起 tile + 内陷进度槽 + 粉彩光晕）、看板/工具栏（凹槽 tab + 凸起滑块、粉彩主按钮）、科目三栏（凸起栏 + 内陷卡片托盘）、学生卡（凸起→完成态内陷薄荷）、空态（内陷虚线拖放区）、统计视图/表格/进度条、弹窗/单选/表单/chips/notice、历史记录、Toast、低版本兜底页、移动端断点。
- 交互：`:active` 全部 150ms 切内陷；`:focus-visible` 2px 蓝色描边保证键盘可达；支持 `prefers-reduced-motion`、`hover:none`。
- 布局不变：单屏不滚动主轴、`.subj-panels` 滑屏、`layoutOne()` 的 `--sw/--sh` 契约全部保留；按审计报告**不增加垂直占用**（subj-grid margin 归零、padding/gap 回到原值附近），避免 1366×768 下触发 `tiny` 隐藏状态文字。
