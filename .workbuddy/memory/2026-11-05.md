## 高校作业考勤系统（单文件网页）

- 产出：`C:\Users\shanxin\Desktop\高校作业考勤系统.html`（约 80 KB，单文件，无构建、无后端）——最终交付位置在桌面根目录，示例名单留在 `Desktop\在校高校系统\`
- 核心约束：导入 xlsx 后**界面全程只显示学号**，姓名仅存 localStorage 不渲染、不进导出表
- 名单操作仅开放三种：新增学生 / 删除学生 / 重置（导入按钮在名单存在后置灰）
- 清点交互：点击卡片标记完成，已完成项保留原位；前 5 名显示 1st~5th 徽章，第 6 名起无徽章
- 重置弹窗两档：仅清空当日 / 清空全部（含名单与历史）
- 数据模型：`{students:[{sid,name,addedAt}], days:{'YYYY-MM-DD':{order:[sid],times:{sid:ts}}}}`
- 完成率 = 该生已完成天数 / 有记录的清点天数（空记录日会被剔除，避免稀释分母）

### 技术要点（可复用）

- **零依赖 XLSX 导出**：手写 OOXML + STORE 模式 ZIP（30/46 字节头 + EOCD + CRC32 表），
  `Blob` 直接下载。三张表：当日作业情况 / 完成率统计 / 历史清点记录。Excel 可正常打开。
- **XLSX 导入**：SheetJS 走 CDN 四级回退（jsdelivr → unpkg → cdnjs → staticfile），
  全失败时提示改用 CSV（内置 CSV 解析，兼容 BOM / 引号 / Tab）。
- 表头识别正则匹配「学号/学籍号/ID」「姓名/名字」，识别不到则按列特征启发式推断。
- 验证方式：Edge `--headless=new --remote-debugging-port` + Node 内置 WebSocket 直连 CDP，
  可跑点击流、`DOM.setFileInputFiles` 真实上传、`Page.captureScreenshot` 回归截图。

### 踩过的坑

- 顶栏 `.topbar-inner` 用 `padding:16px 0 18px` 简写会覆盖 `.wrap` 的左右内边距 → 顶栏贴边且与下方卡片错位。必须拆成 `padding-top/bottom`。
- `position:fixed; left:50%; transform:translateX(-50%)` 的容器宽度默认只有视口一半，
  内部 flex 子项会被压窄换行 → 需 `width:max-content`。
- `.opt .t/.opt .d` 都是 `<span>`（inline），标题和说明会挤在同一行、糊成一段，
  让人误以为"选项点不了" → 必须 `display:block`，外层加 `.opt-body{flex:1}`。
- Python 在 Windows 上写文件默认把 `\n` 转成 `\r\n`；后续用 `newline=''` 读取再按 `\n` 匹配多行模式会失配。

### 第二轮修复（用户反馈）

1. **重置选项点不动**：真因是选项标题/说明同行的排版问题（命中区看起来像一段文字），
   加上选中态太弱。修法：`.t/.d` 改 block、整行 label 点击强制 `input.checked=true`、
   选中态加 3px 光环 + 右上角 ✓。
2. **点击清点整列表闪屏**：原实现每次 `grid.innerHTML = ...` 重建 42 个节点，
   `.card` 上的入场动画 `cardIn` 全部重播。修法：
   - 入口动画挪到 `.grid.anim > .card`，只在列表从空变满时加 `.anim`，480ms 后移除；
   - 新增 `syncCard()` / `applyDayState()` 就地改 class、文字、徽章、完成率条，
     只有列表结构变化（搜索/导入/删除/切页）才 `renderGrid()` 重建。
   - 验证：点击前后 `document.querySelectorAll('.card')[n]` 严格全等，`scrollY` 不变。

### 第三轮：适配学校一体机（部署可用性）

实测结论（Edge headless，file:// 协议）：

- **Chrome/Edge 下所有 `file://` 页面共用同一个 localStorage 存储池**：换目录、改文件名都不丢数据；
  重启浏览器（同一 profile）数据仍在；容量实测约 **5 MB**。
- **CDN 被拦时 xlsx 导入会静默失败**（4 个 CDN 全不可达 → 只有一条 2.4s 就消失的 toast）。
  这对校园网是真实风险。
- 解法：把 SheetJS 0.18.5（881 KB，Apache-2.0）**整段内联**进 HTML，
  文件从 80 KB 变成 940 KB，从此导入/导出全部离线可用；离线实测导入 42 人 + 导出 40 KB 正常。

### 第四轮：单屏铺满（学生上台自己点，禁止滚动）

- `html,body{height:100%}` + `body{overflow:hidden;display:flex;flex-direction:column}`，
  `main.wrap` / `.board` / `#grid` 逐层 `flex:1;min-height:0`，页面永不滚动。
- `layoutGrid()` 枚举列数 c=1..n，算 (w,h)，评分 `w*h*aspectPenalty*fillRatio`，
  aspect 惩罚围绕 1.15，fillRatio = n/(c*ceil(n/c)) 让末行不留空。
  c=7 时 42 人正好 7×6 铺满。
- 密度阈值（用算出的格子像素判定，加 class）：
  - `no-rate` 当 h<126 或 w<150
  - `no-time` 当 h<106 或 w<146（用户要求的"格子小就不显示完成时间"）
  - `no-state` 当 h<72 或 w<100（只留学号+名次）
- **坑1**：`grid-template-rows: repeat(n, minmax(0, Xpx))` 在定高容器里会被压缩
  （21 行被挤成 9.5px）。必须用固定长度 `repeat(n, 110.5px)` + `overflow:auto`。
- **坑2**：`.del` 按钮在 flex 行里占 20px，导致 178px 格子里学号被截成 `20231101...`。
  改为 `position:absolute` 到卡片右上角，学号用满整行；字号系数 0.118。
- **坑3**：手机 390px 塞不下 42 格 → 兜底策略改为"按 150px 最小宽定列数 + 网格内部滚动"，
  而不是把字压到看不清。`align-content` 要跟着从 center 切到 start，否则顶部行滚不到。
- 另加老浏览器兜底：检测 `Promise/TextEncoder/Element.closest` 等，
  不满足就显示「请用新版浏览器打开」并隐藏主界面（IE11 不再白屏）。
- 部署注意：学校一体机常装冰点还原/还原卡，重启清空浏览器数据 → 数据会没，必须靠导出备份。

### 踩的坑

- **函数重复定义不会报错**：patch 时若旧函数残留，后定义的覆盖前面的（hoisting），
  表现为「改了没生效」。改完一定要 `grep -c "function xxx"` 确认只有一处。
- 分节注释的缩进可能被前一次拼接破坏（`/*` 顶格），用固定缩进的锚点会匹配失败；
  改行号索引操作更稳。
- `.card-mid{display:none}` 会连带隐藏里面的徽章；要用 `display:block;height:0` + 绝对定位。
